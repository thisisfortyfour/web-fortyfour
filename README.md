# thisisfortyfour.com

Web de FORTYFOUR. Netlify publica la carpeta `site/` cada vez que hay un cambio en `main`.

- `site/` — la web lista para publicar (no editar a mano).
- `src/` — páginas de diseño (`pages/*.dc.html`) y los scripts que arman `site/`.
- `netlify/edge-functions/` — vista previa al compartir el link de cada proyecto.

El contenido (textos, proyectos, fotos, logos) se edita desde el portal: portal.thisisfortyfour.com → Sitio web.
